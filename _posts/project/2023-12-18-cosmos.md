Sand-Castle Graph is a knowledge-mapping data structure written in Rust. It extends the tree structure of a conventional mind map with **layer nodes** that stack on top of existing concepts, so that a map can represent how ideas build on one another over time, not only how they branch from a central topic.

## Motivation

A mind map radiates from a central concept and represents hierarchy well. It represents sequential development poorly. In robotics, for example:

- individual navigation;
- navigation plus communication gives swarm coordination;
- swarm coordination plus learning gives an adaptive swarm;
- an adaptive swarm plus heterogeneity gives a multi-capability fleet.

Each step depends on the previous one, and a tree has no natural place for that dependency. Tools such as Obsidian handle links between notes but still treat the graph as flat. The layered structure was designed to make this kind of build-up explicit. An earlier graph-algorithms project, finding transfer stations in a subway network, is what got me interested in graph structures in the first place.

## Design

- **Base layer**: ordinary concept nodes with the usual hierarchical and cross links.
- **Layer nodes**: nodes stacked above an existing node, representing a concept that presupposes the one below it.
- **Vertical edges** encode progression; **horizontal edges** encode relations within a layer.
- Layers can be added and removed dynamically, so the structure can grow as a field develops.

## Implementation Status

- Language: Rust.
- Completed: core graph data structure, layer-node logic, node relationship management, dynamic addition and removal of layers.
- In progress: rendering and interactive editing of the layered graph. `egui` and `bevy` are under consideration.
